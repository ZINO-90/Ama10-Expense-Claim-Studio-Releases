# Amaranth10 Expense Claim Studio

더존 Amaranth10의 경비 입력을 돕는 Windows 프로그램입니다. 이 저장소는 설치 파일과 업데이트 정보를 배포합니다.

[최신 버전 다운로드](https://github.com/ZINO-90/Ama10-Expense-Claim-Studio-Releases/releases/latest)

ZIP 전체를 새 폴더에 압축 해제하고 **Amaranth10 Expense Claim Studio.exe**를 실행하세요. Node.js 20 이상·Chrome·Microsoft Edge WebView2 Runtime이 필요합니다. 프로그램 안의 **사용 가이드**에서 사용 방법을 확인할 수 있습니다.

새 버전이 있으면 상단에 **Update** 버튼이 표시됩니다. 누르면 파일을 검증하고 프로그램을 다시 시작합니다. 최초로 업데이트 기능을 지원하는 버전은 직접 설치해야 합니다.

로그인·경비자료·신청서·개인 설정은 각 PC의 Windows 사용자 저장소에서 관리하며 이 저장소로 전송하지 않습니다. 공개 설치 파일에는 개인 API 키와 사내 글꼴을 포함하지 않습니다. 필요한 운임 API 키는 설정에서 입력하세요. 더존체가 설치된 PC는 설치 글꼴을 사용하고, 그 외에는 Noto Sans KR을 사용합니다.

개발 저장소와 변경 이력은 비공개로 관리합니다. 설치 파일에는 프로그램 실행에 필요한 JavaScript 모듈이 포함됩니다.
